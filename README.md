# Huế Street Food Tycoon 🏮🍜

Ứng dụng web game mô phỏng quản lý quầy ăn vặt & ẩm thực Cố Đô Huế (Bún bò Huế, Bánh bèo - nậm - lọc, Cơm hến, Chè hẻm) viết bằng **React**, **Vite**, và **Tailwind CSS**.

## 🚀 Cài đặt & Chạy Local

1. Giải nén file zip.
2. Mở terminal tại thư mục dự án và chạy:
   ```bash
   npm install
   npm run dev
   ```
3. Mở liên kết `http://localhost:5173` để trải nghiệm.
